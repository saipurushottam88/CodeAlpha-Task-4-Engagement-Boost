# CodeAlpha Task 4 — Engagement Boost Project

This project was completed as part of the **CodeAlpha Digital Marketing & Branding Internship**.

## 📌 Project Overview

The objective of this project was to create promotional social media content designed to increase **engagement, followers, brand awareness, and trust** among students and freshers.

## 🎯 Campaign Objectives

- Increase CodeAlpha brand awareness
- Encourage student engagement
- Increase comments and interactions
- Promote internship opportunities
- Build trust through practical learning messaging
- Encourage students to explore technology domains

## 👥 Target Audience

- College Students
- Freshers
- Aspiring Developers
- Technology Learners
- Students looking for internships
- Students interested in skill development

## 📱 Platforms

- LinkedIn
- Instagram

## 🚀 Promotional Creatives

### Creative 1 — Start Your Tech Journey

**Message:**  
Build Skills. Gain Experience. Grow Your Career.

**Focus:** Internship awareness and career growth.

**CTA:**  
Apply • Learn • Grow

---

### Creative 2 — Learn. Build. Get Certified.

**Focus:**  
Practical learning, projects, skill development and career readiness.

**CTA:**  
Start Your Learning Journey

---

### Creative 3 — Which Tech Domain Are You Choosing?

The interactive post presents different technology domains:

- Web Development
- Python
- Data Science
- AI/ML
- Java

**CTA:**  
Comment Your Choice

This creative is designed to encourage students to participate and increase comments and engagement.

## 📈 Engagement Strategy

- Use strong visual content
- Use clear calls-to-action
- Ask questions to encourage comments
- Use relevant hashtags
- Respond to audience comments
- Repurpose successful content into reels and stories
- Maintain consistent posting
